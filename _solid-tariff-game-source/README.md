# Солид Инвестиции — учебный практикум

Браузерная игра по тарифному классификатору и регламенту АО ИФК «Солид». Обучение, блиц, клиентские кейсы, экзамен и разбор ответов со ссылками на источники. Без сервера и API-ключей.

Рабочая публикация: https://seferov-star.github.io/solid-tariff-game/

## Запуск и проверка

Node.js 24. Из каталога исходников:

```sh
npm ci
npm run dev
npm run lint
node --import tsx --test src/game/rules.test.ts src/learning/learning.test.ts
npm run build
```

В `dist` появляется статическая сборка. `base: './'` позволяет размещать её в подпапке Pages. Публикация использует существующий репозиторий `seferov-star/seferov-star.github.io`: содержимое сборки кладётся только в `solid-tariff-game/`. Конфигурацию и другие страницы корневого репозитория менять не требуется. Исходники хранятся в `_solid-tariff-game-source/`, который Jekyll не публикует как сайт.

## Добавление учебной темы

Реестр `COURSES` и типы находятся в `src/learning/courses.ts`. Добавьте запись с постоянным `id`, названием, редакцией источника, PDF, массивом разделов `topics`, банком `items` и правилами экзамена. Интерфейс, фильтры, конспект, счетчики и профили используют этот реестр.

У каждого задания нужны уникальный постоянный `id`, `topicId`, `kind` (`question` / `case`), сложность, вопрос, контекст, четыре различных варианта, `correctIndex`, подробное пояснение, `clauseRef` и номер страницы `sourcePage`. Для регламента также хранится `sourceClause`. `pdf` может быть относительным путем к локальному документу или HTTPS-адресом первоисточника. Ссылки на регламент открывают оригинал на сайте компании.

Не меняйте идентификаторы существующих заданий при редактуре: к ним привязан прогресс. Для существенно новой редакции заведите отдельный идентификатор курса либо явную миграцию. Все разделы должны содержать вопросы и кейсы. Число экзаменационных вопросов должно быть не меньше числа разделов и не больше размера банка вопросов. При отсутствии заданий под фильтр интерфейс сообщает об этом.

`makeDeck` выбирает экзамен по всем разделам с балансом сложности. `shuffleItem` перемешивает копию вариантов один раз при старте сессии и переносит индекс правильного ответа. Пауза и перерисовка не меняют порядок.

## Прогресс и совместимость

Профили хранятся в `localStorage` этого браузера. Серверной авторизации и синхронизации между устройствами нет. Старый ключ `solid_wolf_broker_profiles_v1` сохранён. Перед первой миграцией создаётся резервная копия с суффиксом `_before_courses`, если запись доступна. Старые поля, капитал и история остаются в профиле; новый прогресс хранится в `learning[courseId]`, новые сессии — в `learningHistory`.

## Источники и проверка контента

В новой теме — 116 вопросов и 45 кейсов по 25 учебным разделам. Основной текст PDF охвачен по разделам 1–16. Отдельные приложения, которых нет в документе, требуют самостоятельных источников. Покрытие и сопутствующие замечания: [REGULATION_REVIEW.md](REGULATION_REVIEW.md).

Редактируемый банк — `src/learning/regulations.json`. Авторский генератор — `research/build-regulations.py`. Для его повторного запуска скачайте официальный PDF в `research/regulations.pdf`, установите Python-пакет PyMuPDF, выполните `research/extract.py`, `research/extract-clauses.py`, затем `research/build-regulations.py`. Извлечённый текст нужен только для локальной сверки и в сайт не включён.

Брендинг: логотип и Karst с сайта solidinvest.ru, палитра тёмно-коричневого, золотого и светлого фона. Это учебный тренажёр; учебные бонусы и сертификаты не заменяют реальную квалификационную аттестацию.

## Браузерная проверка

`research/browser-check.mjs` использует Playwright и собранный сайт. По умолчанию ожидает `http://127.0.0.1:8770/dist/`; другой адрес задается `GAME_URL`. Установка браузера: `npx playwright install chromium`. Скрипт проходит все вопросы и кейсы регламента, экзамен, миграцию профиля, изоляцию курсов, подсказки, паузу, таймер и мобильную версию. Результаты и снимки сохраняются в `output/qa/`.
